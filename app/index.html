Cellendar 사용 방법

처음 사용할 때

중요Cellendar에는 반드시 본인의 개인 Microsoft 계정으로 로그인하세요. 학교·회사 계정은 관리자의 승인이 필요하여 연결되지 않을 수 있습니다.
  1. PC에서 OneDrive에 개인 Microsoft 계정으로 로그인합니다.
  2. OneDrive의 내 파일에 이름이 정확히 Cellendar인 폴더를 만듭니다.
  3. Cellendar 앱에서 내려받은 캘린더(자동).xlsx를 그 폴더에 넣습니다.
  4. 파일 이름을 변경하지 마세요. 이름은 반드시 캘린더(자동).xlsx여야 합니다.
  5. 모바일 Cellendar에서 같은 개인 Microsoft 계정으로 로그인하고 동기화 버튼을 누릅니다.

PC에서 Excel을 사용하는 방법

OneDrive 웹에서 사용OneDrive → 내 파일 → Cellendar → 캘린더(자동).xlsx를 열고, 노란 입력표에 일정을 작성합니다. 변경 내용은 자동 저장됩니다.
PC Excel에서 사용PC의 OneDrive 동기화 폴더 안에 있는 Cellendar\캘린더(자동).xlsx를 Excel로 엽니다. 저장하면 OneDrive에 자동 반영됩니다.

파일을 일반 다운로드 폴더나 바탕화면으로 복사해 사용하면 앱과 동기화되지 않습니다. 반드시 OneDrive의 Cellendar 폴더 안에 있는 파일을 사용하세요.

  1. 일정 보기날짜를 누르면 해당 날짜의 모든 일정을 볼 수 있습니다.
  2. 일정 추가날짜 선택 → 일정 추가 → 내용을 입력한 뒤 저장하세요.
  3. 수정·삭제날짜를 누른 뒤 일정 오른쪽의 수정 버튼을 선택하세요.
  4. Excel과 동기화오른쪽 위 ↻ 버튼을 누르면 OneDrive의 캘린더(자동).xlsx와 동기화됩니다.
  5. PC에서 입력Excel의 노란 입력표에서 날짜와 색상을 선택하고 제목을 작성한 뒤 저장하세요.
  6. 연결 확인계정 버튼에서 마지막 동기화 시간과 연결 상태를 확인할 수 있습니다.
  7. 휴대폰 알림계정 버튼 → 휴대폰 일정 알림 켜기를 누르고 알림을 허용하세요. Excel 또는 앱에서 지정한 알림시각에 시스템 알림이 표시됩니다.
인터넷이 없을 때 앱에서 저장한 일정은 다음 연결 시 동기화됩니다. GitHub Pages 방식에서는 앱이 완전히 종료되면 정시 알림이 보장되지 않으므로, 중요한 일정에는 휴대폰 기본 캘린더 알림도 함께 사용하세요.
