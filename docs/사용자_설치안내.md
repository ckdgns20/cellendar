# Cellendar 사용자 설치 안내

## 최초 준비

1. 제공받은 `캘린더(자동).xlsx`를 자기 OneDrive의 `Cellendar` 폴더에 넣습니다.
2. PC에서는 OneDrive에 저장된 이 파일을 Excel로 엽니다.
3. `달력` 시트 오른쪽의 **Cellendar 간편 일정 입력** 표에서 노란 칸만 작성합니다.
4. 날짜와 색상은 셀의 목록 버튼을 눌러 선택합니다. 제목·메모·알림시각은 필요에 따라 입력합니다.
5. 비고 영역은 기존대로 자유롭게 사용할 수 있습니다.
6. 회색 ID·수정시간·삭제시간 칸은 앱이 관리하므로 수정하지 않습니다.
7. 다음 달은 `달력` 시트 상단의 `년도`와 `월` 값만 변경합니다. 날짜 목록도 해당 월에 맞게 자동으로 바뀝니다.
8. 같은 날짜의 일정은 달력 칸에 줄바꿈으로 최대 5개까지 표시되며, 입력표와 앱에는 전체 일정이 유지됩니다.

## iPhone

1. Safari에서 제공받은 Cellendar 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가** → **추가**를 누릅니다.
3. 홈 화면의 Cellendar 아이콘을 실행합니다.
4. Microsoft 계정으로 로그인합니다.

## Android

1. Chrome에서 Cellendar 주소를 엽니다.
2. 메뉴 → **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
3. 설치된 Cellendar를 실행하고 Microsoft 계정으로 로그인합니다.

## 동기화

- 앱 실행 시, 일정 저장·삭제 후, 앱이 열린 동안 5분마다 동기화합니다.
- PC Excel 저장 내용은 OneDrive 업로드가 끝난 뒤 앱에 반영됩니다.
- 인터넷이 없으면 앱에 먼저 저장되고 다음 연결 시 반영됩니다.
- 사용자의 Excel 파일과 일정은 다른 사용자와 섞이지 않습니다.

## 휴대폰 일정 알림

1. Cellendar를 홈 화면에 설치한 뒤 계정 버튼을 엽니다.
2. **휴대폰 일정 알림 켜기**를 누르고 알림을 허용합니다.
3. Excel 또는 앱에서 일정의 알림시각을 지정합니다.
4. 앱이 열려 있거나 백그라운드에 유지되는 동안 지정 시각에 시스템 알림이 표시됩니다.
5. GitHub Pages만 사용하는 방식은 앱이 완전히 종료된 상태의 정시 푸시 알림을 보장하지 않습니다.
